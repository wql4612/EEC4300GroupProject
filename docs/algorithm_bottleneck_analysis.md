# D1–P3 算法瓶颈诊断

近期优先级是约束候选空间、隔离历史效应并解决观测不一致。现有实验评估的是 Prompt 条件，FSCB-Hypo 与 ACB-Hypo 的收益尚未测量。预注册的 P3 放行门槛维持原样。 [P3 深度分析](p3_deep_analysis.md) · [FSCB-Hypo 设计](algorithm_design_v2.md)

## 测量结果

| 问题 | 档案证据 |
| --- | --- |
| Prompt 是否为主要瓶颈 | D1 首轮归档的 15 次 HTTP 返回均未通过当时的语法 Guard，官方解析率为 0。第二次 smoke 的三次返回全部可解析、全部含 NOT，官方 VR、NR、RR 均为 0。D2 的 P0 在 60 槽中 59 槽含 NOT/NOR，P1 降至 30 槽，P2 的 RR 为 14.00%，但 VR 为 16.67%。在 P3 的不同留出组上，P1 首槽 15/15 空间内，P2/P3 各 12/15。三版随后空间内率都降至 36% 以下。D2 与 P3 的样本不同，Prompt 排名不能当成同组复现。 |
| Candidate History | 当前采集器将可提取的候选文本追加到同一条件的历史，越界和观测不一致的候选也可能被追加。P3 后三槽按「历史中已有解析成功的无效候选」分层，有此类历史时 P1/P2/P3 的有效槽分别为 2/30、0/28、6/35；其余为 9/15、13/17、5/10。这是条件关联，早期困难组和早期失败会同时影响分层及后续输出。 |
| 重复如何消耗预算 | 58 个有效槽仅带来 32 个有效新键事件，26 个有效槽重复了已发现键。例如 P1 的 271828–H1 在四次有效输出里得到一个机械键，表达式文本有变化。后三槽共产生 9 个有效新键，Q4 没有任何新增。 |
| 表达式空间与观测一致性 | 180 槽全解析且通过 Guard，97 槽仍越界，另有 25 槽空间内但与观测不一致。深度与禁用算符经常重叠，不能相加。H5 的 15 条空间内候选全部不符合观测；语法约束只能处理其中一类失败。 |
| 控制器可获得的反馈 | P3 的 32 个首次有效键主要集中在 AND-only（20），其余为 OR-only（7）、OR-root mixed（3）和 AND-root mixed（2），跨轨迹累加，含不同轨迹的同键。按首条有效新键之后剩余槽位计算，P1/P2/P3 分别有 29/24/24 个历史窗口。这只是可开始利用历史的上界，实际 Frontier 还受目标桶、连续未命中和动作约束影响。 |

## 推测与待验证假设

- **Prompt 与历史。** P1 首槽更合法，D2/P3 排名又在不同组间变化。Prompt 可能影响起点和示例锚定。将坏候选原文写回可能放大禁用算符或嵌套，也可能只是跟随组难度。固定基础 Prompt 和温度，比较同一新组上的原历史与结构化历史，才能判断历史机制的贡献。
- **候选空间。** 生成阶段限制公开 Grammar 应提高空间内率。H5 表明空间内率的上升未必带来 VR 或 RR 提升，应分别核对语法合规、观测一致性及每槽的有效新键。
- **探索控制。** 若合法且有效的新键更常出现，Controller 才有更多可用的覆盖反馈。FSCB-Hypo 的结构档案提供了可检验机制。P3 没有 LinUCB 动作、前沿暴露或奖励分配记录，无法估计 Controller 是否利用了历史，更无法推断相对 ACB-Hypo 的增益。后续必须配对控制生成器、历史政策、温度刻度、组顺序、预算和种子，保留固定策略及 Random 对照。

离线诊断使用已归档的官方指标。拟议的在线检查只取公开观测、候选及其机械键和轨迹状态，答案键与 RR 仅留在离线评分。 [下一轮研究方案](next_experiment_proposals.md)

## 第三轮 Controller 规范复核

| 核对项 | 离线确认与实施边界 |
| --- | --- |
| 状态 | Basic 取五维，Full 加结构桶占用率。剩余比用尝试槽数，最近反馈窗最多四个有模型反馈槽。基础设施失败消耗槽位、计实发曝光，不进入反馈窗。更新保存决策前状态，只给实发臂。 |
| 六臂与曝光 | 初始仅三个 Standard 温度可用。至少一个有效键、存在未饱和且未触发暂停的桶、前沿文本预算合规时，另开三个 Frontier 温度。分别记录每臂可用、实发和反馈计数；预热仅在可用且反馈未达两次的臂中选。 |
| Frontier | 在资格桶中取最小覆盖比例 c/K，平局按预固定组内顺序。实际命中新键清零目标桶的未命中，真实 Frontier 中的重复、非法或产出其他桶时目标桶加一。连续两次后组内停用。中性提示、Standard 和基础设施错误不修改目标未命中。 |
| 奖励与持久化 | 以决策前的实际产出桶计数计算边际奖励。有效旧键 +0.2，明确无效 −0.5，基础设施失败或有效键缺失不更新参数。以 (run,group,slot) 幂等提交。组间清除候选历史、有效集合、结构计数、未命中计数及窗口；同方法同 Seed 的 A、b 与反馈计数保留，不同方法或 Seed 独立初始化。 |
| 固定、随机及消融 | 固定温度基线全用 Standard。Random 使用相同可用性与预热规则，之后从自身可用臂均匀采样。β=0 保留其他规则。中性前沿保留 arm ID 和等价长度预算，但不更新真实前沿未命中，后续可用性可能自然分化，须报告曝光差异并在解释时计入。 |

七项离线规范夹具全部通过，覆盖可用性、预算与并列、基础与消融奖励、命中逻辑、曝光与幂等、状态隔离、预热和基线。观测验证夹具通过未修改的官方 Validator，只传入公开观测，丢弃返回的候选真值表。夹具是参考预言机，尚无生产控制器实现或在线效应证据。 Controller 离线测试日志（私有证据 `results/p3-third-review-20261126/controller-offline-tests.log`）
